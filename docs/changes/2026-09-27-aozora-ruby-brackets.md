# 青空文庫の〔〕付きルビから括弧を取り除いて表示する（issue #154）

## 背景

青空文庫の新字旧仮名作品（例: 夏目漱石『三四郎』作品ID 58842）では、底本の編集部が補ったルビが
`〔　〕` で括られている。XHTML 版でも EPUB 変換後でも `<rt>〔たし〕</rt>` のように括弧がルビの
文字列そのものに含まれているため、リーダーではルビに括弧がそのまま表示され、小さなルビ文字の中で
括弧が目立って読みにくい。

- 『三四郎』の底本注記: 「※〔　〕内のルビは、編集部による加筆です。」
- 同作品 XHTML の `<rt>` 10,844 件中 342 件が `〔〕` を含む（341 件はルビ全体を括る形、1 件は `〔くん〕じゆ` のように一部だけを括る形）
- `［］` を含む `<rt>` は 1 件のみで、中身は入力者注記 `※［＃濁点付き片仮名エ、514-9］リテ、ヴレイ`。半角 `[]` を含む `<rt>` は 0 件

なお `<rp>（</rp>` `<rp>）</rp>` は既に読み飛ばしており、今回の括弧とは別物。

## 現状の挙動

- 親文字の上（縦書きでは右）に、ルビが括弧ごと表示される。例: 「慥」の上に `〔たし〕`、「難有」の上に `〔ありがた〕`
- 括弧も 1 文字として数えて親文字に配分されるため、括弧の分だけルビが長く詰まって見える

## 変更後の挙動

- ルビの文字列に含まれる `〔`（U+3014）と `〕`（U+3015）を取り除いて表示する。例: 「慥」の上に `たし`、「難有」の上に `ありがた`
- ルビの途中にある場合も取り除く。例: 「群集」の上に `くんじゆ`
- 括弧を除いた後の文字数で親文字に配分する（配分の偏りが出ない）
- 本文（ルビ以外）の `〔〕` はこれまで通り表示する
- ルビが括弧だけだった場合（`<rt>〔〕</rt>` など）は、ルビ無しとして表示する
- 既に開いたことのある本も、更新後に初めて開いたときにページを作り直し、括弧の無いルビで表示される
  （ページ分割のキャッシュを作り直すため、更新後の初回だけ各章の読み込みに時間がかかる）

## スコープ外

- `〔〕` 以外の括弧（`［］` `[]` `（）` など）の扱いは変えない
- ルビ内の入力者注記 `［＃…］`（`<span class="notes">`）の扱いは変えない（本文中の注記と同様、そのまま表示）
- `〔〕` の除去を切り替える設定項目は設けない
- XTC / TXT 形式、目次・書名などルビ以外の表示

- ### 正常系
  - [ ] 横書きで「慥〔たし〕」「難有〔ありがた〕」「生憎〔あいにく〕」のルビが括弧無しで表示される
  - [ ] 縦書きでも同じく括弧無しで表示される
  - [ ] `rb/rp` 無しの形式（`<ruby>屹度<rt>〔きっと〕</rt></ruby>`）でも括弧無しで表示される
  - [ ] 括弧の無い通常のルビ（「田舎者（いなかもの）」など）は修正前と同じ表示
- ### 異常系
  - [ ] ルビ内に注記 `［＃…］` がある段落が、修正前と同じ表示のまま崩れない
  - [ ] 修正前に作られたキャッシュがある状態で開いても、括弧無しで表示される（キャッシュが作り直される）
- ### エッジケース

  - [ ] `［］` `[]` を含むルビは修正前と同じ表示（括弧が残る）
